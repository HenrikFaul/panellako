## Stripe API kompatibilitás (v22.1.1 / 2026-04-22.dahlia)

| Változás | Régi API | Új API |
|----------|----------|--------|
| Subscription period dates | `sub.current_period_start` | `sub.items.data[0].current_period_start` |
| Invoice subscription ID | `invoice.subscription` | `invoice.parent?.subscription_details?.subscription` |

## Paywall logika

```
/w/[buildingId] elérés:
  → subscriptions tábla lekérdezés (service role, RLS bypass)
  → status === 'active' → allow
  → status === 'trialing' AND trial_end > now() → allow
  → egyéb (past_due, cancelled, expired trial) → redirect /billing?building=...
  → subscription record hiánya → allow (új épület, prompt to subscribe)
```
