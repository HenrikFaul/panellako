# v0.5.5 — Keresés, kattintható badge-ek, kapcsolati űrlap

**Date:** 2026-05-16  
**Branch:** claude/setup-project-structure-O56pg  
**Scope:** Header search, clickable metric cards, contact modal with server-side email delivery

## What changed

### New: Header search (real-time inline dropdown)
- `searchItems` memo: indexes navigation, tickets, documents, news, units, meetings, KB articles, vendors
- `searchResults`: filters to max 8 hits on query, ranked by label/type/meta match
- Dropdown renders below input, click-outside + ESC closes
- Each result shows type badge, label, meta; navigates to the section anchor on click

### New: Contact form
- `app/actions/contact.ts` — server action, reads `CONTACT_RECIPIENT_EMAIL` from env (never in frontend code)
- Subject dropdown: Ajánlatkérés / Érdeklődés / Hibabejelentés / Visszajelzés / Partnerség / Egyéb
- 2000 char limit with live counter
- Sends via existing Resend (`lib/email.ts`) infrastructure
- Contact modal: loading, success, error states

### Changed: MetricCard → clickable
- `href` prop added; when set renders as `<a>` with hover scale
- Cards linked: Nyitott ügyek→`#tickets`, Hátralék→`#finances`, Olvasatlan értesítés→`#notifications`, Albetétek→`#units`
- `#notifications` anchor added to Értesítési napló SectionCard
