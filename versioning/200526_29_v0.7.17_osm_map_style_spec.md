# v0.7.17 — OSM custom map style specification (data-first, beauty-second)

**Date:** 2026-05-20
**Branch:** `claude/cycling-routes-sources-sgeIO`
**Scope:** Specification deliverable only — zero application code change. Establishes the renderer-agnostic styling contract for every OSM-driven map surface in the product (dashboard mini-map, environment page, Budapest transit analyzer, cycling explorer, building viewer, future DLC-Brand maps).

## Goal

A single authoritative document that any future agent — human or AI — must read before touching map styling. The spec encodes:

- The **data-first, beauty-second doctrine** (Tier 1–4 OSM features are non-removable; Tier 5 is the only decorative budget).
- A **priority pyramid** for layer z-order and label collision.
- **Five zoom bands** (z0–z6, z7–z10, z11–z13, z14–z16, z17–z20) each with concrete visibility, weight, label-density, and icon-scale rules — plus 20 atomic single-line zoom rules.
- **Four fully differentiated themes** (Minimal Urban Navigation, Beautiful Nature, Dark-Mode Night-Vibe, DLC-Sculpted Brand) — each with its own palette, typography stack, icon language, and decorative budget. All four pass the same data-completeness test.
- **30 layer-by-layer pseudo-JSON blocks** covering 6 road classes, 3 rail classes, transit relations, cycleway + cycle route relations, pedestrian, water, rivers, parks, forest, buildings, POI icons, city / street / neighborhood labels, country / region / municipal boundaries, three landuse classes, and contour lines.
- **Map viewport + UI components** pseudo-HTML (zoom buttons, geolocate, layer + theme switcher, search bar, info panel, mini-map, scale bar, attribution).
- **WCAG 2.1 AA accessibility** rules with explicit color-blindness sub-palettes and `prefers-reduced-motion` handling.
- **Performance budgets** per theme (draw ms, GPU layers, decorative passes), bundle hygiene, sprite + glyph caps.
- **Implementation guide** for MapLibre GL + Protomaps PMTiles + spritezero + fontnik, plus a per-page mapping table.
- A working **example style JSON snippet** (~80 lines) for the Minimal Urban theme that validates against `@mapbox/mapbox-gl-style-spec`.
- A **QA acceptance gate** with 10 explicit pass criteria, including a strict CI diff guard against removing any Tier 1–4 layer.

## Why this deliverable now

Panellako maps are growing across pages (dashboard mini-map, environment NDVI/transit/cycling, building viewer) and we are about to ship marketing-grade hero maps. Without a constitution, each surface drifts: one page hides residential roads "for cleanliness", another deletes house numbers, a third uses a tram color that fails WCAG on dark mode. The spec freezes the contract: **you may restyle anything visual; you may not delete a navigation-critical or information-critical OSM layer.** Any future PR that wants to break that rule must amend this document first, with full governance trail (versioning + marketing value + CHANGELOG bump).

## Anti-regression checklist

- No application code touched (no `app/`, `components/`, `lib/`, `supabase/`, `scripts/` modification).
- No runtime dependency added.
- No build-time dependency added.
- No environment variable touched.
- The four-theme palette respects the brand stack already used elsewhere in the app (Tailwind defaults + Inter + Source Serif Pro + JetBrains Mono + Space Grotesk, all of which are either already loaded by `next/font` in other pages or are system-fallback safe).
- The example style JSON references CDN URLs (`cdn.panellako.hu/...`) that do not yet exist; the spec explicitly marks them as targets, not live endpoints. No DNS or infra change required.
