## Summary

Implements Feature 02 "Zöld Épület Pontszám" — a full standalone page at `/w/[buildingId]/green-score` that computes and displays a 0–100 environmental score for a residential building in Budapest across 6 environmental dimensions.

## Files Added

### `app/api/building-score/[buildingId]/route.ts`
GET endpoint. Auth + active membership check (same pattern as all other building-scoped API routes). Fetches building lat/lon from Supabase `buildings` table; falls back to Nominatim geocoding, then Budapest coordinates (47.4979, 19.0402). Runs 6 sub-score computations in parallel via `Promise.all`:

1. **Air (max 25):** OpenAQ v3 `/locations?coordinates=…&radius=10000` — picks nearest station, reads pm25/pm10/no2/o3, applies EU-limit weighted composite, multiplies by 0.9 + marks as "becsült" if station >5 km away. Default: 12.
2. **Green (max 20):** Overpass — parks/forests/gardens/playgrounds 500 m radius. Nearest park score + area proxy from node count. Default: 8.
3. **Transit (max 20):** Overpass — stop_position/bus_stop/tram_stop/subway 400 m. Stops count score + type bonus (metro+4/tram+3/bus+2/trolley+2, capped 8) + density bonus (4 if ≥3 distinct lines). Default: 10.
4. **Cycling (max 15):** Overpass — cycleways/lanes 300 m + bicycle rental 500 m. Lane-length score + rental count + BuBi proximity bonus. Default: 6.
5. **Noise (max 10):** Overpass — motorway/trunk/primary/secondary roads 150 m. `max(0, 10 - count*3)`. Default: 5.
6. **UHI (max 10):** Overpass — buildings 200 m. `max(0, 10 - floor(count/5))`. Default: 5.

Every external call uses `AbortSignal.timeout(15000)` + try/catch returning defaults.  
Response header: `Cache-Control: public, s-maxage=3600, stale-while-revalidate=600`.  
Returns: `{ total, air, green, transit, cycling, noise, uhi, badge, airEstimated, lat, lon, computedAt }`.

### `app/w/[buildingId]/green-score/page.tsx`
Server component. UUID validation, auth guard (redirect to `/login`), membership check (redirect to `/app`). Supabase building fetch (`id, name, address, lat, lon`). Nominatim geocoding fallback. Budapest coordinate fallback. Passes `buildingId`, `buildingName`, `lat`, `lon` to `GreenScoreDashboardClient`. `generateMetadata` for SEO.

### `components/green-score-dashboard-client.tsx`
Client component:
- **Hero:** SVG circular arc score display (240° sweep, colour-coded by tier), badge pill (Platina/Arany/Ezüst/Bronz/Fejlesztendő with matching Tailwind colours), building name, computed-at timestamp.
- **Sub-score grid:** 2–3 column responsive grid, each card shows score/max, progress bar, icon, label, "becsült" note for air if station was distant, data source attribution.
- **Loading state:** animated skeleton cards.
- **Error state:** red-bordered card with retry button.
- **Frissítés button:** re-fetches score.
- **Attribution block:** lists OpenAQ, OpenStreetMap/Overpass, Nominatim.
- **Back navigation:** `← Vissza a dashboardra` Link to `/w/[buildingId]`.
