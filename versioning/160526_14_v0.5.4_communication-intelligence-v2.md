# v0.5.4 — Communication Intelligence v2

**Date:** 2026-05-16
**Branch:** claude/setup-project-structure-O56pg
**Scope:** Structured announcements, per-user read receipts, reminder engine, multi-mode composer UI

## What changed

### Database (migration: 20260516_communication_v2.sql)
- `announcements` table extended: `scope` (all/owners/residents/specific_units), `priority` (low/normal/high/urgent), `deadline`, `requires_acknowledgement`
- New tables: `announcement_units`, `announcement_reads`, `reminder_rules`, `reminder_sends`
- Full RLS + indexes

### Server actions
- `app/actions/announcements.ts` — fully rewritten with scope-aware targeting, email delivery, read acknowledgement, auto-created reminder rules
- `app/actions/reminders.ts` — new: create/toggle rules, fetch pending recipients, execute idempotent reminder sends

### UI
- `components/announcement-composer.tsx` — new multi-mode composer: 3 message types, audience picker, topic chips, deadline + reminder config, options panel, send summary
- `components/dashboard-client.tsx` — news feed with priority highlighting, "Elolvasva" CTA button, read count for managers; old 3-field form replaced

### Types / data layer
- `lib/types.ts` — NewsItem v2 fields
- `lib/data.ts` — per-user announcement reads fetched and merged

## Risk level
Low — additive schema (all new columns have defaults), backward-compat data layer fallback to mock data, no destructive changes
