- **OSM Overpass API** — 15+ amenity-kategória 1,5 km sugarú körben
- **BKK Transit DB** — transit_stops tábla, 500m bounding box count

## Számítási módszertan

### NDVI
```
NDVI = (B08_NIR - B04_Red) / (B08_NIR + B04_Red)
```
Sentinel-2 L2A SR értékek (0-10000), scale factor kiesik az arányban.

### Gyalogolhatóság (Walk Score decay)
```
score_i = max_weight_i × exp(-distance_i / decay_distance_i)
walkability = min(100, Σ score_i)
```
Például: Supermarket max=25, decay=400m; Gyógyszertár max=20, decay=300m.

### Liveability composite
```
total = greenAir×20% + healthcare×20% + education×15% + culture×15% + services×15% + safety×15%
```
