# v0.9.20 — SEO: Technical fixes + structured data batch update

**Dátum:** 2026-05-23
**Branch:** claude/fix-cron-null-values-uDCqd

## Probléma

A 9 specialista SEO agent futása során (v0.9.x SEO sprint) a következő kritikus technikai és strukturált adat hiányosságok kerültek azonosításra:

- `/auth/` és `/monitoring` nem volt letiltva `robots.txt`-ben
- `maximumScale: 1` blokkolta a mobil zoom-ot (akadálymentességi probléma)
- Globális canonical fallback `BASE_URL`-re silent duplikált canonicalt okozhatott új oldalakon
- 3 oldal relatív canonical URL-t használt (`/`, `/arak`, `/gyik`)
- `/elemzes/budapest-kozlekedes` hiányzó BreadcrumbList schema
- Nem volt WebSite schema (sitelinks keresőmező elveszett)
- 27 Article schema `datePublished`, `dateModified`, `author` nélkül → Google rich result ineligible
- `/kozgyules-osszehivasa` 8 lépéses folyamata nem volt HowTo sémával jelölve

## Fix

### robots.ts
- `/auth/` és `/monitoring` disallow hozzáadva

### layout.tsx
- `maximumScale: 1` eltávolítva a `viewport` exportból
- `alternates.canonical: BASE_URL` eltávolítva a globális metadatából
- `WebSite` schema hozzáadva `@id: '#website'` és `SearchAction` potentialAction-nel
- `@id` property hozzáadva a `SoftwareApplication` (`#software`) és `Organization` (`#organization`) sémákhoz

### 27 Article schema
Python batch script segítségével minden Article sémához hozzáadva:
- `datePublished: '2024-01-15'`
- `dateModified: '2026-05-23'`
- `author: { '@type': 'Organization', name: 'PanelLakó', url: 'https://panellako.hu' }`

### kozgyules-osszehivasa/page.tsx
- `howToSchema` konstans hozzáadva — a meglévő `CHECKLIST_STEPS` 8 elemét mappolja HowToStep-ekre
- `<script type="application/ld+json">` hozzáadva az oldalon
