### Implementation summary

#### A) `.github/workflows/ci.yml` — 6 párhuzamos job

| Job | Trigger-gate | Tartalom |
|-----|-------------|----------|
| `typecheck` | mindig | Node 20, `npm ci`, `npm run typecheck` (`tsc --noEmit`) |
| `lint` | mindig | Node 20, `npm ci`, `npm run lint` (`next lint`) |
| `build` | `needs: [typecheck, lint]` | Node 20, `npm ci`, `npm run build` stub `NEXT_PUBLIC_SUPABASE_*` env-ekkel |
| `gitleaks` | mindig (full history) | `gitleaks/gitleaks-action@v2`, `.gitleaks.toml` |
| `semgrep` | mindig (konténerből) | `semgrep ci --config=auto --config=.semgrep.yml`, SARIF → Code Scanning |
| `trivy` | mindig | `aquasecurity/trivy-action@master` fs-scan, CRITICAL+HIGH, SARIF → Code Scanning |

- **`concurrency: ci-${{ github.ref }}`** + `cancel-in-progress: true` — PR push elnyomja az előzőt, spórol Actions-minute-öt.
- **Permissions:** `contents: read`, `security-events: write` (SARIF upload-hoz CodeQL action-nel), `pull-requests: write` (gitleaks-action PR-commenthez).
- **Build env stubok:** `NEXT_PUBLIC_SUPABASE_URL=https://example.supabase.co`, `NEXT_PUBLIC_SUPABASE_ANON_KEY=stub-anon-key-for-ci-build`, `NEXT_TELEMETRY_DISABLED=1`. Mivel `experimental.typedRoutes: true` a `next.config.mjs`-ben, a build-step ezeket olvassa, de soha nem ér el Supabase-t (CI-ben nincs runtime hívás).

- **Schedule:** hétfő 04:00 Europe/Budapest, max 10 nyitott PR.
- **Labels:** `dependencies`, `automerge-candidate` (kézzel kell majd egy GitHub Action automerge-re — kihagytuk a scope-ból).
- **`github-actions` ecosystem** külön: heti, `chore(ci)` prefix, `dependencies` + `ci` label.

#### C) `renovate.json` (alternatíva)

Jobb DX a Dependabothoz képest. Aktiválás: GitHub App telepítése a repóra (`https://github.com/apps/renovate`). A fájl jelenléte önmagában **nem** aktiválja, így biztonságos itt hagyni.

- `:automergeMinor` + `group:allNonMajor` + `:prHourlyLimit2` → kevesebb noise.
- Patch-all egy csoportba, branch-szintű auto-merge.
- `sharp` és `@react-pdf/renderer` heavy native dep-ek külön csoport, `stabilityDays: 7`, **nincs** auto-merge — ezek a leginkább törésre hajlamosak (Lanczos3 NDVI pipeline, PDF generation).
- `lockFileMaintenance` heti hétfő 5:00 — package-lock.json frissítés security-update-ek nélkül.
- `vulnerabilityAlerts: { labels: ["security"], automerge: false }` — security-PR-eket ember review-zza.

**Döntés a usernek:** Dependabot **vagy** Renovate, **nem** mindkettő egyszerre (különben duplikált PR-ek). A repo most már mindkét configra fel van készítve, csak választani kell.

#### D) `.gitleaks.toml`

- `[extend] useDefault = true` — gitleaks beépített 100+ rule-ja (AWS, GCP, Azure, GitHub, generic JWT, generic API key).
- 6 panellako-specifikus rule:
  - `supabase-service-role-key` — JWT minta (`eyJ...\.eyJ...\.[A-Za-z0-9_-]{40,}`).
  - `supabase-service-role-key-assignment` — env-var assignment, hogy a JWT-minta nélküli leak-eket is fogja.
  - `stripe-secret-key` — `sk_(live|test)_...`.
  - `stripe-webhook-secret` — `whsec_...`.
  - `resend-api-key` — `re_...`.
  - `sentry-dsn-with-secret` — legacy DSN secret-szegmenssel.
- Allowlist a fals pozitívokhoz: lockfile-ok, `CHANGELOG.md`, `codingLessonsLearnt.md`, `cycling-data-sources/*.md`, `stack_audits/*.md`, `map_styles/*.md`, `growth_strategy/`, `valuation/`, `doc creation/`, `marketing/*.md`, `versioning/*.md`. Egy konkrét regex-allowlist: a `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleGFtcGxlIjoidHJ1ZSJ9` példa-JWT, ami doku-fájlokban szerepel.

#### E) `.semgrep.yml`

4 custom rule, ami a `p/nextjs p/typescript p/react p/owasp-top-ten p/secrets` registry ruleseteket egészíti ki:

1. **`no-service-role-in-client-or-page-component`** (ERROR) — a `SUPABASE_SERVICE_ROLE_KEY` szándékkal a server-side island-ekre korlátozva: `app/api/**`, `app/superadmin/**`, `app/**/route.ts`. Bárhol máshol = build-blocker bug.
2. **`no-anon-key-in-superadmin-api`** (WARNING) — superadmin API-k szinte mindig service-role-t használnak (admin nem akar RLS-fal verekedni). Anon-key megjelenése itt valószínűleg hiba.
3. **`no-fetch-without-timeout`** (WARNING) — `app/api/**` és `lib/**` alatt a `fetch($URL)` `AbortSignal.timeout()` nélkül 300 s Pro / 10 s Hobby function-budget-ig lóghat. A Nominatim / Open-Meteo / NASA GIBS WMS / OSM Overpass mind külső, lassú API.
4. **`no-console-log-in-production-route`** (INFO) — `lib/log.ts` strukturált logger-t kell használni `app/api/**`, `app/w/**`, `app/superadmin/**` alatt a Sentry/OTel trace-correlation miatt. (A `lib/log.ts` az Agent A scope-ja — ha még nem létezik, ez a rule csak INFO szinten szól, nem blokkol.)

#### F) `scripts/check-secrets.sh`

- `#!/usr/bin/env bash`, `set -euo pipefail`, `chmod +x` (754 oktett).
- `command -v gitleaks` ellenőrzés telepítési útmutatóval (brew / scoop / GH release).
- `gitleaks detect --source=$PATH --config .gitleaks.toml --verbose --no-git` — ugyanazt a `.gitleaks.toml` configot futtatja, mint a CI, így nincs drift.
- Husky / lint-staged / pre-commit dependency NULLA.

### Assumptions / risks flagged

- **Public repo / GitHub Advanced Security:** a SARIF upload `security-events: write`-tal a Code Scanning UI-ba megy. Public repón ez ingyen működik; ha a repo privát-ra váltana, GHAS feature kell.
- **gitleaks-action license:** csak az org-tier large enterprise-eknél kéri a `GITLEAKS_LICENSE` titkot, solo / small team free.
- **Dependabot vs Renovate aktiválás:** mindkettő config bekerül, **csak egyiket aktiváld**. Dependabot alapból aktív (configfile-jelenlét = aktív), Renovate-hoz a GitHub App telepítése kell — `renovate.json` jelenléte önmagában nem aktivál.
- **Az első CI futás várhatóan WARNING-okkal jön** — a `.semgrep.yml` 4 rule-ja még nem volt élesben futtatva a kódbázison; a `no-fetch-without-timeout` és `no-console-log-in-production-route` valószínűleg több hit-et ad. A WARNING / INFO szint **nem blokkol**, csak jelez — followup-task lesz a hit-ek triagolása.
- **trivy fs-scan skip-dirs:** `node_modules`, `.next`, `growth_strategy/fonts`, `valuation/fonts` ki van zárva (large binary font-ok és buildtermékek).
- **build job stub env:** elegendő a `next build` lefutásához (a `route.ts`-ek import-time olvassák a Supabase env-eket, de csak runtime hívnák meg az API-t — CI-ben nincs runtime call).
- **A `.husky/` pre-commit hook szándékosan kimaradt** (user kérése: minimal scope, nulla új npm dep). Helyette `scripts/check-secrets.sh` manuálisan futtatható.
