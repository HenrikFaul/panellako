# v0.7.0 — Cycling data sources backend specification pack

**Dátum:** 2026-05-19
**Branch:** `claude/cycling-routes-sources-sgeIO`
**Típus:** Új specifikációs csomag (research/spec pack — nem alkalmazás-kód)

## Mit ad

Új `cycling-data-sources/` mappa 25 MD-fájllal. Mindegyik egy magyarországi vagy magyar
felhasználás szempontjából releváns kerékpáros adatforrásra ad **teljes backend tervet**:
forrás-áttekintés, jogi/licenc helyzet, adatkinyerési felület (API/Overpass/GPX/PBF/PDF),
hitelesítés és rate-limit, forrás-oldali és cél-oldali (PostGIS) adatmodell,
8-rétegű architektúra (ingestion → staging → parser → normalizer → storage → serving → cache → observability),
automatizált letöltő (futtatható Python ~80–250 sor), feldolgozó pipeline, frissítési stratégia,
monitoring, költségbecslés, biztonság, tesztelés, telepítés (Docker + k8s CronJob + GitHub Actions),
adatpublikálás (REST + vector tile), runbook, roadmap, referenciák.

Az állományok mérete forrásonként ~36–53 ezer karakter, összesen ~1 077 000 karakter.

## Sajátosságok

- **OSM/Overpass** (04, 26, 15): Geofabrik PBF (~620 MB hungary, ~85 GB planet), osmium/osm2pgsql,
  daily/hourly replication diffs, ISO2 LIST partíciók.
- **Routing motorok** (13, 12, 18, 19, 20): partner API + OAuth2 elsődlegesen, scraping TILTOTT/utolsó esély,
  OSM háttérdatabase fallback.
- **Magyar hivatalos források** (01, 02, 08, 28): polite scraping, Infotv. 28. § adatigénylés sablon,
  PDF/XLSX parser (pdfplumber + camelot + openpyxl), SHA-256 snapshot diff.
- **Magyar közösségi források** (03, 05, 06, 07, 24, 11, 23, 29): polite 1–3 req/s, robots.txt-respect,
  azonosítható User-Agent kapcsolattartó e-maillel, partnerség-kérés a scraping előtt
  (`*_SCRAPE_ENABLED` env flag-gel kikapcsolva alapból).
- **GBFS** (28): BKK MOL Bubi minutely GBFS poll, TimescaleDB hypertable.
- **Offline OSM appok** (16, 17): elsődlegesen Geofabrik OSM PBF + pyosmium handler,
  audit a natív `.obf` / `.mwm` formátumokkal.
