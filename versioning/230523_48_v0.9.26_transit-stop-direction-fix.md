**Dátum:** 2026-05-23

## Probléma

A transit térkép útvonal-részletező paneljén duplikált megállónevek jelentek meg és
a megállók sorrendje helytelen volt. Gyökérok:

1. `gtfs_stop_times` tábla üres (az import nem töltötte fel a per-trip stop schedule-t)
2. Fallback: `transit_stop_routes` tábla — tartalmazza **mindkét irány** összes megállóját
   direction szűrés és sorrend nélkül
3. Eredmény: ~2× annyi megálló jelent meg, helytelen sorrendben, azonos nevű megállók
   mindkét irányból (ellentétes peronok)

## Megoldás

### `app/api/transit/shape/route.ts`

**Új függvény: `haversineM()`**
- Két GPS koordináta közötti távolság számítása méterben
- A geometriai projekcióhoz szükséges

**Új függvény: `projectStopsOntoShape(stops, shapePoints)`**
- A `transit_stop_routes` fallback irány-helyes rendezéséhez
- **1. lépés**: Minden megállót vetít a közelítő shape pontjaira → along-track index + perpendicular distance
- **2. lépés**: Ellentétes peron deduplication: azonos nevű megállók 500 m-en belül → csak a shape-hez legközelebb lévő marad (= helyes irány)
- **3. lépés**: Maradék megállók rendezése along-track index szerint
- Megállók > 2 km-re a shape-től eldobásra kerülnek (nem ezen az útvonalon vannak)

**Módosítás: `fetchShapeFromDb()`**
- `direction_id` hozzáadva a `gtfs_trips` queryhez → `TripShape.directionId` exportálva
- `gtfs_stop_times` keresés: az összes ID variánst próbálja (nem csak `variants[0]`)
- Fallback limit: 80 → 200 (mindkét irány → felezés után elegendő)
- Fallback: `projectStopsOntoShape()` hívás a sorrend + deduplication megoldásához
- Visszaadja: `directionId`, `routeRef` (üres string helyett üres string ha ismeretlen)

**`TripShape` interface**
- `directionId?: number` mező hozzáadva (0 = főirány, 1 = visszairány)

### `components/transit-live-map-inner.tsx`

- `tripInfo` state: `directionId?: number` hozzáadva
- `setTripInfo()`: `directionId` beállítása az API válaszból
- **Header UI**: Irány nyíl chip `→` (direction 0) / `←` (direction 1) a route badge után
- **Stop count badge**: "N megálló" felirat a stop lista tetején
