# v0.5.3 — Document Management for Managers

**Date:** 2026-05-16  
**Version:** 0.5.3  
**Branch:** `claude/setup-project-structure-O56pg`

## Summary

Adds full document lifecycle management for `kozos_kepviselo` and `megbizott` roles: inline metadata editing, delete with confirmation, and one-click demo document initialization. Generates 4 realistic A4 PDF demo documents and provides an API route to upload them into Supabase Storage.

## Changes

### Server actions (`app/actions/documents.ts`)
- `deleteDocument(id, buildingId?)` — deletes from both DB and Storage bucket (manager role check)
- `updateDocument(id, updates, buildingId?)` — patches title/category/version/visibility (manager role check)
- Shared `assertManagerRole` helper reused by both actions

### API route (`app/api/init-demo-docs/route.ts`)
- GET/POST — reads PDF files from `public/demo-docs/`, uploads to `documents` bucket under `demo/` prefix, updates DB records from legacy URLs to storage paths
- Idempotent: `upsert: true` on storage upload, UPDATE where file_url matches legacy pattern

### Demo PDF generation (`scripts/generate_demo_docs.py` + `public/demo-docs/`)
- 4 PDFs generated with ReportLab: SZMSZ, Éves elszámolás 2025, Közgyűlési meghívó, Tűzvédelmi szabályzat
- Each PDF: A4, Panellako brand colors, realistic Hungarian content with tables and sections
- PDFs checked into `public/demo-docs/` for static serving + server-side reading

### UI (`components/dashboard-client.tsx`)
- Edit button (pencil icon) on each document card — manager-only, opens inline form
- Delete button with "Biztosan törlöd?" confirmation step — manager-only
- Demo init amber banner: visible to managers when documents have legacy storage.panellako.hu URLs; one-click uploads files and updates DB

### Database
- `supabase/migrations/20260516_fix_demo_document_urls.sql`: UPDATE for legacy URL migration
- `supabase/seed.sql`: URLs updated to correct storage paths for fresh installs

## Roles affected
- `kozos_kepviselo`: can edit and delete documents
- `megbizott`: can edit and delete documents
- `lako` / `tulajdonos`: read-only (no change)
