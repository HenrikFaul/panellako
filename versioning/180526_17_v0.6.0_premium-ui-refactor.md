# v0.6.0 — Premium UI/UX Refactor

**Date:** 2026-05-18  
**Branch:** claude/setup-project-structure-O56pg  
**Type:** UI/UX Enhancement

## Summary

Full premium design-system upgrade across all key screens. Elevates the visual quality from a functional dashboard to a polished, trustworthy B2B SaaS product. No business logic, routes, or data flows were changed.

## Design Philosophy

Target character: **megbízható · elegáns · nyugodt · rendezett** (trustworthy · elegant · calm · orderly) — a premium "digitális műveleti központ" for property managers and residents.

## Changes

### Foundation
- **Inter font** loaded via `next/font/google` with `latin-ext` — proper OpenType features enabled
- **Tailwind config** extended: custom shadow scale, spring timing, stagger animations, border-radius tokens
- **globals.css** redesigned: CSS custom properties, `.glass`, `.card-lift`, `.input-base`, `.btn-primary`, `.btn-secondary` utilities

### Building Picker (`/app`)
- Sticky frosted-glass header with user avatar initials
- Cards: staggered `fade-in-up` reveal, lift-on-hover, animated ping dot for open tickets
- Gradient icon badge, MapPin address line, cleaner role badges

### Login (`/login`)
- `scale-in` entry animation
- Status message color-coded (error vs success)
- Unified input/button utilities

### Dashboard (`/w/[buildingId]`)
- SectionCard: cleaner border/shadow, icon container with ring
- MetricCard: `via` gradient stops, icon in frosted container, lift hover
- Sidebar: refined opacity tokens, role panel icon, `duration-150` nav transitions
- Hero section: building name displayed prominently with address; CTA lift microinteraction
- StatusBadge/PriorityBadge: Hungarian labels, consistent ring style
- Task cards: `card-lift`, softer background
- All form inputs unified to `input-base`
- All action buttons unified to `btn-primary`/`btn-secondary`

## Non-breaking guarantees
- All routes, auth flows, data fetching unchanged
- No new dependencies (only `next/font/google`, already part of Next.js)
- TypeScript: 0 errors
- ESLint: 0 warnings
