# v0.9.4 — Közösségi Zöld Akciók (Feature 05)

**Date:** 2026-05-22
**Branch:** claude/fix-cron-null-values-uDCqd

## Summary

Implements the "Közösségi Zöld Akciók" (Community Green Actions) feature as a standalone page at `/w/[buildingId]/zold-akciok`. Fully client-side MVP using localStorage for persistence — no new Supabase tables required.

## Files Added

### `app/w/[buildingId]/zold-akciok/page.tsx`
Server component with the same auth guard + membership check pattern as `/w/[buildingId]/zaj/page.tsx`:
- UUID validation → 404 if invalid
- Supabase auth check → redirect to `/login` if unauthenticated
- Membership check → redirect to `/app` if not a member
- Building lookup → passes `buildingId` and `buildingName` to client component
- `generateMetadata` for SEO title/description

### `components/green-actions-client.tsx`
`'use client'` component implementing 3 sections:

**Section 1 — CO₂ Megtakarítás Kalkulátor**
- Trip distance slider (0–50 km, default 5)
- Transport mode selector: Autó / BKK / Kerékpár / Gyalog
- "Kiszámol" button → CO₂ comparison table (Autó 0.21 kg/km, BKK 0.082 kg/km, others 0)
- "Rögzítem" button → saves trip to localStorage (up to 10 entries)

**Section 2 — Saját Közlekedési Napló**
- Reads last 10 trips from `pl_trip_log` localStorage key
- Monthly CO₂ savings summary (sum of current-month entries)
- "Törlés" link to clear history
- SSR-safe hydration via `useEffect` + `hydrated` flag

**Section 3 — Épületi Zöld Akciók**
- 6 static green action cards with icon, title, description
- "Szavazok rá!" toggle button (local React state, resets on reload)
- Fake vote counter starts at random baseline (3–15), increments on click

## Technical Decisions
- All state is client-side: localStorage for trip log, React `useState` for votes/UI
- `typeof window !== 'undefined'` guard in `loadTrips` / `saveTrips` for SSR safety
- Dark theme (bg-slate-950) matching other workspace pages
- Emerald color accent for the green/environmental theme
- No new npm packages
- ESLint: 0 errors, 0 warnings
