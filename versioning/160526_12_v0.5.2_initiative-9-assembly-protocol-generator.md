# v0.5.2 — Közgyűlési Segéd: Assembly Protocol Generator (Initiative #9)

**Date:** 2026-05-16
**Branch:** claude/setup-project-structure-O56pg
**Version:** 0.5.2

## Summary

Completes Initiative #9: Assembly Protocol Generator. Managers can now record attendance, track resolutions, and generate legally-structured PDF minutes (Közgyűlési Jegyzőkönyv) for every general assembly — fully integrated with the dashboard UI via a new slide-over detail panel.

## Files Changed / Created

### New
- `supabase/functions/generate-assembly-protocol/index.ts` — Deno Edge Function; builds an A4 PDF with 6 sections (building info, meeting info, quorum, attendees, agenda+resolutions, signatures), uploads to Supabase Storage `documents` bucket, updates `meetings.protocol_url`.
- `components/meeting-detail-panel.tsx` — Slide-over panel: quorum progress bar, per-unit attendance toggle, agenda items + resolutions with Elfogad/Elutasít buttons, manager actions (invitation, close meeting, generate/download PDF).
- `supabase/migrations/20260516_assembly_protocol_policies.sql` — INSERT/UPDATE/DELETE RLS policies for meetings, agenda_items, resolutions, votes, meeting_attendances.
- `app/api/storage-signed-url/route.ts` — GET endpoint for Supabase Storage signed URL generation (10 min TTL), used by meeting-detail-panel for PDF download.

### Modified
- `app/actions/meetings.ts` — Added: `addResolution`, `updateResolutionOutcome`, `removeAttendance`, `getMeetingWithDetails`, `generateProtocolManually`. Updated: `closeMeeting` now triggers edge function fire-and-forget.
- `components/dashboard-client.tsx` — Meeting cards now open `MeetingDetailPanel` on click; fixed `buildingId` bug in `closeMeetingAction` (was passing `meeting.id`).

## Technical Notes

- PDF uses `pdf-lib@1.17.1` via esm.sh CDN in the Deno Edge Function. Hungarian characters (á, é, ő, ű, etc.) are transliterated to ASCII because Helvetica (StandardFont) lacks extended Latin glyphs.
- `getMeetingWithDetails` is a server action called from the client component on panel open; returns meeting, agenda_items, resolutions, attendances.
- Protocol storage path: `assembly-protocols/{building_id}/{meeting_id}.pdf`

## Deployment Steps

1. `supabase functions deploy generate-assembly-protocol`
2. Apply migration via SQL Editor: `supabase/migrations/20260516_assembly_protocol_policies.sql`
3. Verify `documents` storage bucket exists in Supabase project
