## Goal

Önálló, repo-specifikus, részletes (8–15k karakteres) AI-stack-optimalizációs jelentés készítése a teljes panellako codebase-re, **3 cost-tier szerkezetben**:

| Tier | Cél-spend | Target persona |
|------|----------:|---------------|
| Tier 1 | ≈7 €/hó (~84 €/év) | Bootstrap solo dev |
| Tier 2 | ≈99 €/hó (~1 188 €/év) | Team-of-1 going pro |
| Tier 3 | ≈248 €/hó (~2 976 €/év) | Funded team |

A jelentés a "**Ultra-Brutal AI Stack Strategist & Cost Optimizer**" prompt-specifikáció szerint készült, **belül 7+ iterációval** (raw draft → extra tech → tier-balance → hiányzó rétegek → AI-strategy → risk-walkthrough → final polish). Az iterációk eredménye a jelentésbe épül, de a folyamat **NEM** szerepel az outputban (a spec ezt kifejezetten tiltja).

### Repo-specifikus erősségek kihasználása

- **Meglévő `pgmq + pg_cron + pg_net` Supabase-extension-mátrix** (`supabase/migrations/20260520_cycling_extensions_and_schemas.sql`) — a jelentés ezt javasolja **Kafka helyett, 0 €/hó-n**. A repo már enabled-i őket, csak nincs standardizált queue-contract.
- **A 25-source `cycling-data-sources/*.md` spec pack** mint **few-shot library** AI-asszisztált adapter-generáláshoz (~1 €/source × 25 = 25 € one-off).
- **`crazy_innovations/system.md` 5-iter kreativitás-protokoll** — már produkált egy frissen merge-elt asset-et (v0.7.15 dashboard-hero-scene), institutionalizálandó minden új UI-surface előtt.
- **`full-stack-e2e-prompt-ecosystem/end_to_end_full_stack_verification.prompt`** — Sonnet API-n keresztül futtatva **free CI gate** lesz, helyettesíti a jelenlegi humán-screenshot-review-t.
- **Stripe + `tenant_subscriptions.tier_id` + `superadmin_change_workspace_tier` RPC** (CLAUDE.md non-negotiable) — billing rails **kész** AI-feature-ek tier-gating-jére.

### Hidden risks (10 db, mind a jelentés 8. szekciójában)

1. Nominatim ToS — 1 req/sec/IP cap, in-memory cache cold-start-evaporation
2. `sharp` cold start a Vercel 100 MB lambda-ceiling közelében
3. Zero CI test gate (humán-screenshot-review-only)
4. `superadmin-auth.ts` single-secret, no rotation, no audit log
5. `platform_job_logs` unbounded — 60 napon belül a legnagyobb tábla lesz
6. Service-role-key leak audit grep hiánya CI-ban
7. No Cloudflare in front of Vercel — `app/api/transit/budapest-overview` 80 000 GTFS-point response cache-mentesen
8. NDVI master tier 100 MB PNG → Supabase Storage egress
9. In-memory cache cold-start evaporation Vercel-en
10. No off-site WAL archive

### 7+ iteráció során azonosított extra technológiák (a jelentésbe épültek)

- **Kafka helyett pgmq** (a Tier 3 alacsonyan tartására)
- **Inngest / Trigger.dev** mint pgmq-UI alternatíva (de a jelentés **elveti** a Tier 2-n, mert overkill)
- **OpenTelemetry → Grafana Cloud Free** (50 GB logs + 50 GB traces ingyen, 14 nap)
- **Sentry Dev (free) → Team (25 €/hó)** progresszió
- **Cloudflare R2** zero-egress storage a NDVI master tierhez (Supabase Storage egress kiváltása)
- **Cloudflare Workers + WASM sharp** a NDVI Lanczos3 upscale off-loading-jához (a 100 MB Vercel-lambda-ceiling kerülése)
- **Snyk Code** + **gitleaks pre-commit** + **Semgrep CE** + **Trivy** — full security toolchain 0 €/hó Tier 1-en
- **Renovate Bot** (Dependabot kiegészítése)
- **Chromatic visual diff** (a leaflet basemap és a dashboard-hero CSS-keyframe regresszió fogására)
- **PostHog Cloud free** (1 M event/hó) feature-funnel tracking-re
- **Neon read-replica branching free tier** (Supabase read-replica add-on 10 €/hó kiváltása)

## Risks & mitigations

| Kockázat | Mitigáció |
|----------|-----------|
| Az audit-ajánlások végrehajtása több hetes engineering work — összemoshatóvá válik a "audit kész" és "stack frissítve" állapot | A jelentés 9. szekciójában **90-day execution roadmap** explicit lebontva hét-szintre, hogy a követő PR-ek tisztán azonosíthatók legyenek (Week 1–2: CI test + gitleaks; Week 3–4: OTel + Sentry; Week 5–8: Supabase Pro + Vercel Pro; Week 9–12: NDVI → R2 + Worker). |
| A cost-szám-becslések árfolyam-függőek (USD → EUR) | Minden USD-ben listázott vendor-nál szerepel a "≈X €" átszámítás aktuális ~0.94 USD→EUR rátán. ±5% mozgás belefér a tier-ceiling-be. |
| Vendor-pricing változhat | A jelentés a 2026-05-20 állapotot rögzíti; a `stack_audits/` mappa időbeli rétegekre nyitva — jövőbeli audit-PR új filename-mel kerül be (`panellako_ai_stack_optimization_audit_v2.md` stb.). |
| Az "internal 7-iter story" elhagyása a outputból nem ellenőrizhető | A jelentés tartalom-minősége önmagában bizonyítja az iteráció-mélységet (10 réteg × 3 tier + hidden-risk + roadmap). Nem mock-listák. |
