## Goal

Az eddigi statikus dark-night panelház-sziluett helyére egy **élő, ambient SVG-jelenet** kerül, ami a felhasználó valós napszaka és évszaka szerint változik. A cél, hogy a dashboard egy pillantásra "élőnek" érződjön: a 8:00-kor belépő felhasználó reggeli sárga eget, a 14:00-kor belépő nappali kék eget, a 22:00-kor belépő csillagos eget lásson — anélkül, hogy ez bármilyen funkcionalitást elvenne vagy figyelmet vonna el a valódi tartalomtól.

Ez a Crazy Innovations doktrína egyenes alkalmazása: **maximális kreativitás, de a felhasználói orientáció (situational awareness) és termék-memorabilitás szolgálatában** — nem cool-but-pointless dekoráció.

## Implementation details

### Napszak-detektálás (`detectTimeOfDay`)
| Időablak | Napszak | Példa skygradient |
|----------|---------|-------------------|
| 05:00–06:59 | `dawn` | `#ea580c → #fbbf24 → #fed7aa` (narancs→barack) |
| 07:00–09:59 | `morning` | `#fbbf24 → #fde68a → #fef3c7` (meleg sárga) |
| 10:00–15:59 | `day` | `#38bdf8 → #7dd3fc → #bae6fd` (világos kék) |
| 16:00–18:59 | `afternoon` | `#fde68a → #fbbf24 → #fef3c7` (arany) |
| 19:00–20:59 | `sunset` | `#ea580c → #f97316 → #fed7aa` (narancs naplemente) |
| 21:00–22:59 | `evening` | `#1e1b4b → #312e81 → #4338ca` (mély indigó) |
| 23:00–04:59 | `night` | `#010610 → #040e24 → #0d2248` (mély éjszakai) |

`setInterval(60_000)` re-evaluálja percenként — egy nyitva hagyott dashboard maga is "végighalad" a napon.

### Évszak-detektálás (`detectSeason`)
JavaScript `Date.getMonth()` (0-11) alapján:
- 2-4 → `spring` (március–május)
- 5-7 → `summer` (június–augusztus)
- 8-10 → `autumn` (szeptember–november)
- 11, 0, 1 → `winter` (december–február)

A session során nem változik (havi újra-eval felesleges); a `useMemo` rögzíti.

### Égitest pozíciója (`sunY`)
A nap/hold y-koordinátája a napszakhoz kötött, így a hajnal és naplemente alatt **alacsonyan a horizonton** látszik (y=92), nappal magasan (y=18). Ez a sky-gradient-en kívül erős időbeli jel.

### Évszak-rétegek
- **Tavasz**: zöld lombú fák `#4ade80`/`#22c55e` + rózsaszín virág-pötty `#fbcfe8` / `#f9a8d4`
- **Nyár**: sűrű erős zöld `#16a34a` + alkalmi pillangó az 1. fa felett (`panellako-twinkle` 7s ciklus)
- **Ősz**: narancs-piros lomb `#ea580c` + hulló levelek (7 db, 9–15 mp-es eső + 540° forgás, x-irányú sodródás `--drift` CSS variable-rel)
- **Tél**: csupasz törzs + ág-`<line>` rajz + ágon hósapkák + globális hóesés (22 hópehely, 9–17 mp esés, alpha fade-in/out)

### Animációk
Minden CSS `@keyframes`, scope-olva a komponens `<style>` blokkjában:
- `panellako-twinkle` — opacity csillag-pulzálás
- `panellako-rotate` — csillagkép cluster forgása
- `panellako-flicker` — ablak villogás (~36% lit windows random delay-jel)
- `panellako-cloud` — felhő bal-irányú sodródás (50–80 s)
- `panellako-tram` — villamos átvágás bal→jobb (11 s, `forwards`)
- `panellako-snow` — hópehely esés (transform translate3d + opacity)
- `panellako-leaf` — levél esés forgással
- `panellako-shoot` — shooting-star (30 s ciklus, 5% láthatóság-ablak)

A `prefers-reduced-motion: reduce` media query az összeset kikapcsolja:
```css
@media (prefers-reduced-motion: reduce) {
  .panellako-anim { animation: none !important; }
}
```

### Villamos timing
`setTimeout` lánc: első villamos 5–15 s után, utána random 25–45 s-os intervallumokban. Mount-kor a `tramKey` 0, így első render villamos nélkül indul, ami megelőzi a hidratációs villanást.

### Performance budget
- Komponens ~28 KB (gzipped várhatóan ~6 KB)
- A véletlen-pozíciók (`stars`, `snowflakes`, `leaves`, `clouds`, `constellations`) **mount-kor egyszer** generálódnak `useMemo` + `mulberry32(1337)` deterministic seed-del — minden render-en azonos pozíciók (no layout thrash).
- Csak `transform` és `opacity` animálódik → composite layer, no paint, no layout. 60fps GPU-only.
- Re-render trigger csak: napszak-váltás (max 1×/perc), villamos-újra (25–45 s).

### Komponens API
```tsx
<DashboardHeroScene
  forceTimeOfDay?: 'dawn' | 'morning' | 'day' | 'afternoon' | 'sunset' | 'evening' | 'night'
  forceSeason?: 'spring' | 'summer' | 'autumn' | 'winter'
  className?: string
/>
```

A `force*` prop-ok superadmin/demo/screenshot-célre használhatók (pl. landing-page preview "így néz ki éjszaka").

## Risks & mitigations

| Kockázat | Mitigáció |
|----------|-----------|
| iOS Safari nem támogat `transformBox: 'fill-box'` minden verzión a constellation forgáshoz | A csillagok és más elemek pozíció-fix; csak a constellation cluster érintett. iOS 14+ támogatja. Régebbi: a constellation egyszerűen nem forog, de látszódik. |
| Mobil-akkumulátor a folyamatos animációtól | `prefers-reduced-motion` Apple/Android energiatakarékos módban gyakran beállítódik → minden mozgás megáll. Egyébként csak `transform`/`opacity` → compositor-only, ~0% CPU. |
| Hidratációs villogás (server vs client time difference) | A komponens `'use client'`; az SSR és kliens is az aktuális `new Date()`-et használja. Mivel `forceTimeOfDay` nincs default-ban, és az SSR `new Date()` ≈ kliens `new Date()` (másodperces eltérés a napszak-bucket-en belül), nincs észrevehető villogás. |
| Régi PanelSkylineSvg törlés okozta build-warn | Nem törlöm — bent marad mint dead code, jövőbeli cleanup-PR témája. |
