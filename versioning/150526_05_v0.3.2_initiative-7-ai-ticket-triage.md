## Összefoglaló

Initiative #7 (AI-Powered Fault Ticket Triage) implementálása. Új hibabejelentés mentésekor a rendszer fire-and-forget módon meghív egy Supabase Edge Functiont, amely Anthropic claude-haiku-4-5 modellel 2–4 másodperc alatt elvégzi a triázst: 8 kategória, 1–10 sürgősségi pontszám, vendor javaslat (HU), egymonatos összefoglaló (HU). Manager felülbírálhatja az AI döntést.

## AI mezők (tickets tábla)

| Oszlop | Típus | Leírás |
|--------|-------|--------|
| `ai_category` | text | plumbing / electrical / structural / common_area / emergency / hvac / elevator / other |
| `ai_urgency` | integer 1–10 | 1–4: rutinkarbantartás, 5–7: mielőbb, 8–9: sürgős, 10: életveszély |
| `ai_vendor_suggestion` | text | Magyar nyelvű szakember javaslat |
| `ai_summary_hu` | text | Egymonatos magyar összefoglaló |
| `ai_triage_at` | timestamptz | NULL = triage folyamatban / sikertelen |
| `ai_override` | boolean | TRUE ha manager felülbírálta |

## Edge Function tájékoztató

- **Deploy:** `supabase functions deploy triage-ticket --no-verify-jwt`
- **Secret:** `ANTHROPIC_API_KEY` beállítása Supabase Dashboard → Project Settings → Edge Functions → Secrets
- **Fallback:** Ha az API key nincs beállítva vagy a hívás sikertelen, a ticket `ai_triage_at = null` marad — a UI pending skeleton állapotot mutat, de nem törik meg

## UI változások

- **Pending állapot:** animate-pulse skeleton jelenik meg az AI mezők helyén
- **AI urgency badge:** emerald (1–4) / amber (5–7) / rose (8–10+!) szín, Sparkles ikon
- **AI kategória chip:** kategória-specifikus szín (pl. sky = vízvezeték, amber = elektromos, rose = vészhelyzet)
- **Vendor javaslat:** kis szürke szöveg az AI row-ban
- **High urgency:** urgency ≥ 8 esetén a ticket kártya rose kerettel és háttérrel emelkedik ki
- **Override modal:** manager "AI módosítás" gombra kattintva megnyílik — kategória select + urgency range slider
