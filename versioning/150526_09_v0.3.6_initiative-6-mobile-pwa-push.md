## PWA konfiguráció

- **Display mode**: `standalone` (teljes képernyős, böngésző nélkül)
- **Theme color**: `#0f766e` (teal)
- **Language**: `hu`
- **Offline**: `/offline` fallback oldal service worker-en keresztül

## Push architektúra

1. Frontend: `navigator.serviceWorker.ready` → `pushManager.subscribe()` → POST `/api/push/subscribe`
2. Backend: push_subscriptions tábla (endpoint, p256dh, auth kulcsok)
3. Edge Function: `send-push` — VAPID JWT generálás, Web Push API hívás, expired subscription tisztítás
4. Invoke pattern: Server Action → Edge Function `send-push` → összes subscriber

## VAPID key generálás

```bash
npx web-push generate-vapid-keys
```

## Deployment előfeltételek

- `NEXT_PUBLIC_VAPID_PUBLIC_KEY` — publikus kulcs (Next.js és Edge Function)
- `VAPID_PRIVATE_KEY` — privát kulcs (server-side only, Vercel env + Supabase secret)
- `VAPID_SUBJECT` — `mailto:support@panellako.hu` (Supabase secret)
- Edge Function deploy: `supabase functions deploy send-push --no-verify-jwt`

## iOS megjegyzés

- iOS 16.4+ szükséges a Web Push támogatáshoz
- A push toggle gomb `'PushManager' in window` detection alapján jelenik meg — iOS < 16.4 esetén rejtve marad
- iOS-on a "Főképernyőre adás" manuális lépés (nem automatikus install prompt)
