# v0.6.1 — ActivityCalendar: Multi-Event Calendar with Scope Parameterization

**Date:** 2026-05-18  
**Branch:** claude/setup-project-structure-O56pg  
**File changed:** `components/dashboard-client.tsx`

## What changed

Replaced the single-type `TicketHeatmap` (only showed ticket counts as a rose gradient heatmap) with a fully parameterized `ActivityCalendar` component that aggregates all building lifecycle events.

### Event sources

| Category | Source | Scope | Color |
|----------|--------|-------|-------|
| Hibabejelentés (ticket) | `tickets[]` prop | 🏠 Albetét (or 🏢 Épület if no unit) | `#f43f5e` rose |
| Közgyűlés (meeting) | `meetings[]` prop | 🏢 Épület | `#3b82f6` blue |
| Szavazás (vote) | `meetings[]` where `agenda_preview` contains "szavaz" | 🏢 Épület | `#f59e0b` amber |
| Mérőóra határidő (meter deadline) | Auto-generated: 20th of each visible month | 🏢 Épület | `#10b981` green |

### Visual changes

- **Cells:** Past days show colored dots per category present (not just a single background color); dominant category still drives background.
- **Future days:** Soft highlight if upcoming events exist (meetings, meter deadlines visible weeks ahead).
- **Tooltip:** Events grouped by category with scope badge (🏢/🏠/👤), unit label shown per ticket if available. Future event cells labeled "Közelgő esemény".
- **Legend:** Replaced single-category rose gradient bar with 4 category chip labels.

### Scope parameterization

New types `EventScope` and `EventCategory` make it trivial to extend with additional scopes or categories. Votes are automatically detected from meeting `agenda_preview` text (keyword "szavaz"). `currentUnit` prop passed to show which unit's tickets appear in tooltip.

## No regressions

Existing ticket display logic preserved. Component receives same `tickets` prop shape. `meetings` prop was already available in the parent render.
