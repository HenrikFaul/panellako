## UHI Calculation Algorithm

```
UHI_estimated (°C) = BASE_UHI × K_density × K_green × K_water × K_park × SEASONAL_FACTOR[month]

BASE_UHI = 2.0°C (Budapest városi alap)
K_density = 0.8 + (building_density_percent / 100) × 0.8   // 0.8 → 1.6
K_green   = 1.5 - (green_coverage_percent / 100) × 1.0     // 1.5 → 0.5
K_water   = 0.9 ha van víztest 500m-en, különben 1.1
K_park    = 0.95 ha van park 300m-en, különben 1.05
SEASONAL_FACTORS: Jan=0.60, ..., Júl=1.25 (csúcs), ..., Dec=0.60
```

KlímaScore = UHI-komponens (40pt) + levegőminőség (30pt, fallback 20) + árvíz (30pt, fallback 20)

## Key Design Decisions

1. **Nincs külső chart könyvtár** — A havi diagram tiszta SVG; recharts nincs a package.json-ban, nem adtuk hozzá.
2. **24h modul-szintű cache** — Overpass API hívásonkénti lat/lon (3 tizedesjegy pontosság) kulccsal.
3. **Fallback rétegek** — Overpass sikertelen → Budapest moderált default (45% beépítettség, 15% zöldfelület, 5 hardcoded hűsölőhely).
4. **localStorage checkbox** — ClimateActionPlan 8 elem állapota `panellako_klima_actions` kulcson tárolódik.
