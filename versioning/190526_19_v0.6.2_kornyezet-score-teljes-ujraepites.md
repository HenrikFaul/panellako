# v0.6.2 — KörnyezetScore™ Teljes Környezetoldal Újraépítés

**Dátum:** 2026-05-19  
**Ág:** claude/fix-cron-null-values-uDCqd  
**Típus:** Új funkció (major)

## Összefoglalás

A `/kornyezet` oldal teljes újraépítése. A korábbi 2-tabos, AQICN-alapú design helyett egy 6-szekciós, görgetős, IntersectionObserver-alapú lazy-load architektúra lépett; minden API ingyenes és kulcs nélküli.

## Új API route-ok

| Fájl | Leírás |
|------|--------|
| `app/api/environment/air-quality/route.ts` | Open-Meteo AQ: PM2.5/PM10/NO2/O3/SO2/CO/UV/pollen, 30 perces cache, US EPA AQI konverzió |
| `app/api/environment/weather/route.ts` | Open-Meteo Weather: szél, csapadék, UV, nap, 60 perces cache |
| `app/api/environment/solar/route.ts` | PVGIS EU JRC kWh/kWp/év, havi bontás, 30-napos Supabase cache |
| `app/api/environment/green/route.ts` | OSM Overpass parkok/fák/játszóterek/zaj, Shoelace terület, 7-napos cache |
| `app/api/environment/score/route.ts` | KörnyezetScore™ kompozit (35+25+15+10+15 súlyok) |

## Új komponensek

| Komponens | Leírás |
|-----------|--------|
| `env-score-hero.tsx` | Animált SVG kör-gauge + 5 alpontsáv |
| `sparkline-24h.tsx` | Pure SVG 24h PM2.5 + UV sparkline egér-tooltippal |
| `pollen-panel.tsx` | Nyír/fű/parlagfű szintjelzők + 7-napos forecast |
| `uv-wind-panel.tsx` | WHO UV gauge + szélirány-iránytű |

## Adatbázis migrációk

- `building_green_cache` — Overpass eredmények 7-napos TTL-lel
- `building_solar_cache` — PVGIS eredmények 30-napos TTL-lel
- `building_env_score` — Kompozit pontszám

## Superadmin bővítések

- `env_refresh_green` job: minden épületre Overpass-frissítés, 7-napos cache-kihagyás, 2 s-os közbülső késleltetés
- Stats tábla: `environment` csoport 3 új táblával

## Technikai döntések

- **Open-Meteo**: ingyenes, kulcs nélküli, Copernicus CAMS pollen + AQ egy URL-ről — felváltotta az AQICN-t
- **PVGIS**: EU JRC publikus API, 30-napos cache megakadályozza az ismételt lekérdezést
- **Overpass**: IntersectionObserver lazy-load — a 30 másodperces lekérdezés csak görgéskor indul
- **KörnyezetScore™**: súlyozott formula, Budapest ~58/100 benchmark
