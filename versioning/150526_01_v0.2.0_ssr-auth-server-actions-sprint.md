## Implementációs részletek

### SSR Auth Pattern

```typescript
// middleware.ts — session refresh minden kérésnél
await supabase.auth.getUser(); // nem getSession()

// lib/supabase/server.ts — cookie-alapú kliens Server Componentekhez, Server Actionsökhöz
createServerClient(url, key, { cookies: { getAll, setAll } });
```

### Server Actions pattern

```typescript
'use server';
export async function createTicket(input: CreateTicketInput) {
  const supabase = createClient(); // szerver-oldali
  const { data: { user } } = await supabase.auth.getUser(); // mindig aktuális
  await supabase.from('tickets').insert({ ...input, reporter_id: user?.id });
  revalidatePath('/'); // Next.js cache invalidation
}
```

### Optimista UI frissítés

A ticket létrehozásnál és státusz váltásnál az UI azonnal frissül (optimistic update), a szerver szinkron a háttérben fut — ez jobb UX a hosszú hálózati késleltetés esetén.
