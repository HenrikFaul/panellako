# v0.9.6 — Területfelhasználás Térkép a Környezet Oldalon

**Date:** 2026-05-22
**Branch:** `claude/fix-cron-null-values-uDCqd`
**Type:** Feature

## Summary

Added an interactive land-use / territory map to the `/kornyezet` (environment) page, showing OSM-sourced land use categories as colored polygon overlays centered on the building.

## Files Added

### `components/land-use-map-inner.tsx`
`'use client'` Leaflet component. On mount:
- Fetches Overpass API via POST to `https://overpass-api.de/api/interpreter` with `AbortSignal.timeout(20000)` and a 1000 m radius query covering `landuse`, `leisure=park/garden`, `natural=wood/scrub/grassland`
- Converts Overpass `geometry` arrays to GeoJSON Feature objects via `overpassWayToGeoJson()`
- Renders polygons with `L.geoJSON` style function:
  - Park/garden: `#22c55e` (green-500)
  - Forest/wood: `#15803d` (green-700)
  - Grassland/meadow: `#84cc16` (lime-500)
  - Scrub: `#65a30d` (lime-600)
  - Residential: `#64748b` (slate-500)
  - Commercial/retail: `#f97316` (orange-500)
  - Industrial: `#94a3b8` (slate-400)
  - Farmland/allotments: `#eab308` (yellow-500)
  - Other landuse: `#475569` (slate-600)
- All polygons: `fillOpacity: 0.35`, `weight: 0.8`, `opacity: 0.5`; click → popup with tag value
- Dark CARTO tile layer (`dark_all`)
- Indigo building dot marker (same SVG pattern as `cycling-map-inner.tsx`)
- Bottom-left legend: colored squares + Hungarian labels (Park, Erdő, Rét/fű, Lakó, Kereskedelmi, Ipari, Mezőgazdaság)
- Loading state: "Területfelhasználás betöltése…" animated pulse text
- Error state: map renders with building marker + "Adatok nem elérhetők" overlay
- Height: `h-72`
- `import('leaflet')` inside `useEffect` — never at module level

### `components/land-use-map.tsx`
SSR-safe wrapper using `dynamic(() => import('./land-use-map-inner'), { ssr: false })`. Exports `LandUseMap`. Loading fallback: animated pulse skeleton matching map height.

## Pattern Followed

Exactly matches `cycling-map-inner.tsx` / `cycling-map.tsx`:
- `useRef<any>(null)` for map instance
- `let destroyed = false` cleanup flag
- `async IIFE` inside `useEffect`
- `L.map()` + tile layer + marker + `mapRef.current.remove()` on cleanup
- `setTimeout(invalidateSize, 300)` for container reflow
- Dynamic import wrapper with `ssr: false`

## Testing Notes

- ESLint: zero errors on all three files
- No new npm packages required (leaflet already a dependency)
- Overpass query uses `out geom` to get inline geometry — no separate `out body` + `>` step needed
- Relations are fetched but only `way` elements (which have `geometry`) are rendered; relations without member geometry are silently skipped
