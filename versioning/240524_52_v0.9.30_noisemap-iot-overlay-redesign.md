# v0.9.30 — Noise Map: IoT overlay + multi-layer architecture redesign

**Dátum:** 2026-05-24
**Branch:** claude/fix-cron-null-values-uDCqd

## Probléma

A zajriporter térkép egyetlen WMS rétegből állt; váltáskor az egész Leaflet-térkép újra inicializálódott. IoT (állampolgári) mérések nem voltak elérhetők. A WMS forrásdiagnosztika hiányzott (nem volt látható, melyik upstream szerver válaszolt).

## Változtatások

### `components/noise-map-inner.tsx` — teljes újratervezés
- **3 független React-effect** az egységes useEffect helyett:
  - Effect 1: Leaflet térkép init (deps: koordináták + téma)
  - Effect 2: WMS réteg csere (deps: mapReady + wmsLayer) — térkép-reinit nélkül
  - Effect 3: IoT lekérés/megjelenítés (deps: mapReady + iotEnabled)
- **IoT toggle gomb**: "IoT mérések (NoiseCapture)" — bekapcsoláskor lekéri a `/api/noise/iot-measurements` végpontot
- **`dbToColor()`** helper: EU END 2002/49/EC standard skála alapján szín hozzárendelés a mérési értékekhez
- **`probeWmsSource()`** modul-szintű függvény: az első tile betöltése után 1×1px WMS kérést küld, olvassa az `X-Noise-Source` headert, és megjeleníti az attribúciós badge-ben
- **IoT `L.circleMarker`** renderelés: tooltip-pel (dB érték + időpont + forrás)
- **Állapotok**: `tileStatus`, `wmsSourceId`, `iotStatus`, `iotCount`, `iotEnabled`
- IoT "unavailable" értesítő ha a NoiseCapture endpoint nem elérhető

### `app/api/noise/iot-measurements/route.ts` — új fájl
- Budapest bbox proxy a Noise-Planet/NoiseCapture API-hoz
- Két endpoint próbálva sorban (mindkettő "unverified" jelölésű — endpoint-útvonal megerősítésre vár)
- GeoJSON normalizáló: GeoFC + nyers mérési tömb formátumokat kezel
- In-memory cache: 1 óra TTL
- Fallback: üres FeatureCollection `status: 'unavailable'` + provenance megjegyzéssel

### `docs/NOISE_MAP_ARCHITECTURE.md` — új fájl
- Forrás-leltár (3 WMS + 2 IoT forrás), licencek, attribúció
- QA validáció mátrix, hibamód kézikönyv, IoT acquisition terv
- Deployment & refresh policy, dB skála dokumentáció

## Technikai megjegyzések

- A WMS proxy (`/api/noise/wms-tile`) változatlan — a `X-Noise-Source` header már előző PR óta adott
- TypeScript: `npx tsc --noEmit` — 0 hiba
- IoT mérések opcionálisak: a stratégiai WMS réteg az IoT nélkül is teljes funkcionalitással működik
