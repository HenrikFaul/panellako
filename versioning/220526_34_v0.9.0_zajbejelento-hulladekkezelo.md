## Feature 07: Zajbejelentő (Traffic Noise Reporter)

### Útvonal
`/w/[buildingId]/zaj`

### DB (migration: `20260522_noise_reports.sql`)
- `noise_category` ENUM: `forgalmi_zaj`, `epitkezesi_zaj`, `szrakozohely_zaj`, `repulo_vonat`, `ipari_zaj`, `egyeb`
- `noise_period` ENUM: `ejszaka`, `reggel`, `nappal`, `este`
- `noise_reports` tábla: workspace_id (→buildings), reporter_id (→auth.users), severity 1–5, duration 1–480 perc, estimated_db 30–120, description max 500 char, is_recurring
- Index: `idx_noise_reports_workspace` (workspace_id, occurred_at DESC)
- RLS: SELECT és INSERT nyilvános

### API
- `POST /api/noise/reports` — validáció + insert
- `GET /api/noise/reports?workspace_id=` — utolsó 90 nap
- `GET /api/noise/heatmap?workspace_id=` — dátum × napszak aggregáció (count, avg_severity)

### Komponensek
| Fájl | Leírás |
|------|--------|
| `components/noise-report-form.tsx` | Bejelentő form: kategória dropdown, 1–5 star severity, napszak-gomb, duration slider, dB input, textarea, ismétlődő checkbox |
| `components/noise-heatmap.tsx` | 7×4 rács (utolsó 7 nap × 4 napszak); szín: white/5 → amber → red; API-ból tölt |
| `components/noise-health-advisory.tsx` | WHO/EEA Lnight táblázat + Budapest zajtérkép link |
| `components/noise-dashboard-client.tsx` | 3 fül: Bejelentés / Naptár / Egészségügyi tanácsok |
| `app/w/[buildingId]/zaj/page.tsx` | Szerver page: auth + tagságellenőrzés + metadata |

## Feature 12 (waste): Hulladékgazdálkodás

### Útvonal
`/w/[buildingId]/hulladek`

### DB (migration: `20260522_waste_reports.sql`)
- `waste_reports` tábla: workspace_id, month (DATE, UNIQUE/workspace), 5 kategória kg (paper, plastic, glass, organic, electronic), households_participating, notes
- `illegal_dump_reports` tábla: workspace_id, category (5 elem), lat/lon, status (uj/folyamatban/megoldva)
- RLS: SELECT és INSERT nyilvános mindkét táblánál

### API
- `POST /api/waste/reports` — UPSERT havi adat (onConflict workspace_id,month) vagy `type=illegal_dump` lerakás bejelentés
- `GET /api/waste/reports?workspace_id=` — utolsó 12 hónap

### Lib
- `lib/waste-co2-factors.ts` — EEA tényezők (paper 0.70, plastic 1.50, glass 0.30, organic 0.10, electronic 4.50 kg CO₂/kg) + `calcWasteCO2Savings()` + `calcTotalWasteKg()`

### Komponensek
| Fájl | Leírás |
|------|--------|
| `components/waste-tracker-panel.tsx` | Havi bevitel (szám + slider), live CO₂ hero kártya, CSS sávdiagram (recharts nélkül — nincs a dep-ek között) |
| `components/illegal-dump-reporter.tsx` | Bejelentő form GPS gombbal (navigator.geolocation), kategória, leírás |
| `components/waste-dashboard-client.tsx` | 3 fül: Hulladékjelentés / Szabálytalan lerakás / Körzeti rangsor |
| `app/w/[buildingId]/hulladek/page.tsx` | Szerver page: auth + tagságellenőrzés + metadata |

Körzeti rangsor: Budapest 23 kerület statikus táblázat (FKF 2024 hardcoded), azonnali tartalom recharts/API függőség nélkül.

## Technikai döntések

1. **Recharts nincs a package.json-ban** → CSS-alapú sávdiagram implementálva a `waste-tracker-panel`-ben
2. **`createClient()` szinkron** (nem async, a `lib/supabase/server.ts`-ben `cookies()` szinkron) → nincs `await` a route-okban
3. **Nincs i18n** — az app nem használ centralizált i18n-t, minden szöveg magyar inline
4. **GPS opt-in** — `navigator.geolocation` csak explicit gombnyomásra fut, nem automatikusan
5. **RLS nyilvános** — mindkét modul bárki által olvasható/írható a `memberships` validáció a szerver page-en van
