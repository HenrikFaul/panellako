# v0.7.16 — AI-Stack-Optimalizációs Audit (3 cost-tier)

## 1. Feature name and version

**Repo-szintű AI-stack-optimalizációs audit, 3 cost-tier szerkezetben** — `panellako v0.7.16`. Egy önálló, ~14 800 karakteres jelentés (`stack_audits/panellako_ai_stack_optimization_audit.md`), ami a teljes panellako stack-re ad rétegenkénti (10 réteg) vendor-választást Tier 1 (≈7 €/hó) / Tier 2 (≈99 €/hó) / Tier 3 (≈248 €/hó) költség-keretben.

## 2. One-sentence user-language description

A panellako mostantól nemcsak egy lakásszövetkezet-kezelő SaaS, hanem egy **bizonyítható módon költség-optimalizált, AI-vezérelt infrastruktúrával** működő platform — minden eurós kiadásra meg tudjuk mondani, miért szükséges, és mekkora növekedési tier-en aktiválódik.

## 3. Problem it replaces

A piacon a legtöbb SaaS-versenytárs **vakon költ** SaaS-tooling-ra (Datadog 70 €/hó, Sentry Team 25 €/hó, AWS RDS 100 €/hó stb.) anélkül, hogy számszerűen tudná, milyen méretű kockázatot vagy growth-velocity-t vásárol érte. A panellako most rendelkezik egy **élő, audit-MD-formátumú döntési térképpel** — minden új vendor-kiadás-javaslat azonnal lokalizálható a Tier 1/2/3 mátrixban, és összevethető a meglévő tervekkel.

A korábbi gyakorlat: bekapcsolunk egy Sentry-t, megrémülünk a számlától, kikapcsoljuk. Az új gyakorlat: tudjuk, hogy a Sentry Tier 2-ben még a Free tier elég, és csak Tier 3-on lépünk a Team-re — a Tier 3-as Sentry-Team költség 25 €/hó, a teljes Tier 3 keret 248 €/hó-ja 10%-a, és **a NDVI tile-rendering cold-start-bug-jainak fél napos debug-jával az első hónapban visszahozza az árát**.

## 4. Primary beneficiary persona(s)

- **Founder / solo dev (panellako tulajdonos)** — most már egy oldalon látja, hogy a következő 3 hónap mikor és miért kell skálázni a SaaS-spendet (~7 → 99 → 248 €/hó). 90-day execution roadmap heti bontásban.
- **Befektető / VC due-diligence reviewer** — egy auditálható dokumentum, amiből látszik, hogy a CAC/LTV szempontból kulcsfontosságú **infra-OPEX teljes mértékben kontrollált**, és a Tier-progresszió diszciplináltan kapcsolódik a revenue-növekedéshez.
- **Partner-CTO / co-founder candidate** — az audit önmagában is egy **engineering-trust signal**: a repo nemcsak governance-ben (CLAUDE.md, .governance/), hanem cost-engineering-ben is enterprise-grade.
- **Felvásárló / acquihire ajánlattevő** — a `stack_audits/` mappa a `valuation/` és `growth_strategy/` mappákkal együtt egy **prebuilt due-diligence csomag**.
