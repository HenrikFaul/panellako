# Marketing Value — v0.4.0: Multi-Building Dashboard + Building Picker

## 1. Feature name and version
**Multi-Building Dashboard + Building Picker** — v0.4.0 (Initiative #5)

## 2. One-sentence user-language description
Egy fiókkal, egy kattintással váltasz bármely kezelt épület között — PanelLakó mostantól ügynökségek és több épületet kezelő közös képviselők igazi munkaeszköze.

## 3. Problem it replaces
Több épületet kezelő közös képviselők és ingatlankezelő ügynökségek eddig kénytelenek voltak különböző böngészőprofilokat, session-ket vagy kézzel beírt URL-eket használni. PanelLakóban nem volt "épület váltás" funkció — minden felhasználó csak egy épületet látott.

## 4. Primary beneficiary persona(s)
- **Közös képviselő (több épülettel)** — 2–10 épületet kezel egyszerre, azonnali váltás nélkül eddig nem volt lehetséges
- **Ingatlankezelő ügynökség (ügynökség)** — 8–25+ épületet kezel, a portfólióláthatóság a belépési feltétel a platform adoptálásához
- **Könyvelő** — több épület pénzügyeit kezeli, épület-szintű szűrés nélkül az adatok összekeveredtek

## 5. Marketing-ready claim
„Kezeld az összes épületedet egy helyen — PanelLakóval egy kattintással váltasz épületek között, és minden adat pontosan arra az épületre vonatkozik, amelyiket éppen nézed."

## 6. Claim types enabled
- **Skálázhatóság** — 1 → N épület ugyanazon fiókból, lineáris növekedés lehetséges
- **Hatékonyság / időmegtakarítás** — nincs többszörös bejelentkezés, nincs böngészőtab-zsonglőrösség
- **Adatpontosság** — minden mutató épület-szintű, nincsenek összekevert adatok
- **Piaci differenciáció** — a hazai konkurens termékek (Társasház Manager, ImmoPROFI) nem rendelkeznek multi-épület nézettel

## 7. Content angles

1. **LinkedIn post**: „Az ingatlankezelő ügynökségek miért nem találnak megfelelő szoftvert? Mert a legtöbb rendszer egyszerre csak egy épületre tud fókuszálni. PanelLakó v0.4.0 megoldja ezt."
2. **Case study hook**: „Egy 18 épületet kezelő budapesti ügynökség így takarít meg heti 4 órát az épületek közötti váltással"
3. **SEO article**: „Multi-tenant társasházi szoftver: mit kell tudnia, ha egyszerre több épületet kezel?"
4. **Feature comparison**: „PanelLakó vs. Társasház Manager: melyik skálázódik az ügynökséged méretéhez?"
5. **Conversion hook**: „Ha több mint 3 épületet kezelsz, a PanelLakó ügynökségi nézete 30 percen belül beállítható — próbáld ki ingyen."

## 8. Funnel stage
- **Consideration** — a multi-épület capability az ügynökség szegmens legfontosabb döntési kritériuma
- **Conversion** — enterprise és ügynökségi ügyfelek számára ez az on-ramp feature
- **Retention** — épületek közötti adatmegosztás és áttekinthetőség platform-lock hatást teremt
