# Marketing Value — v0.3.6: Mobile PWA + Push Notifications

## 1. Feature name and version
**Mobile PWA + Web Push Notifications** — v0.3.6 (Initiative #6)

## 2. One-sentence user-language description
PanelLakó telepíthető az okostelefonra és valós idejű értesítéseket küld közleményekről, hibajegyekről és közgyűlésekről — appstore nélkül, teljesen ingyenesen.

## 3. Problem it replaces
A lakók eddig csak akkor értesültek a ház ügyeiről, ha aktívan beléptek a weboldalra. Fontos közlemények, sürgős hibabejelentések és közgyűlési meghívók elvesztek az e-mail zajban, vagy egyáltalán nem jutottak el a lakókhoz.

## 4. Primary beneficiary persona(s)
- **Lakó (bérlő vagy tulajdonos)** — azonnali értesítést kap minden lényeges eseményről anélkül, hogy e-mailt kellene böngésznie
- **Közösképviselő / házkezelő** — a fontos üzenetek biztosan eljutnak a lakókhoz, nő a reagálási arány

## 5. Marketing-ready claim
„Telepítsd a PanelLakót okostelefonodra és soha ne maradj le a ház eseményeiről — push értesítések, appstore nélkül."

## 6. Claim types enabled
- **Engagement / elérés növelése** — azonnali push értesítés vs. e-mail olvasottság
- **Kényelem** — natív alkalmazás élmény telepítés nélkül (PWA)
- **Koordináció** — közösképviselő egyetlen kattintással értesít minden lakót
- **Visszatartás (retention)** — telepített ikon az asztali képernyőn növeli a napi visszatérési arányt

## 7. Content angles

1. **LinkedIn post**: „Egy társasházi app, amit nem kell appstore-ból letölteni — hogyan használja a PanelLakó a Progressive Web App technológiát?"
2. **SEO article**: „Mi az a PWA és miért ideális a társasházi kommunikációhoz?"
3. **Case study hook**: „X %-kal nőtt az értesítések olvasottsága, mióta push értesítéseket küld a ház — egy fővárosi társasház tapasztalata"
4. **Feature demo**: „30 másodperc alatt telepítsd a PanelLakót iPhone-odra — lépésről lépésre"
5. **Conversion hook**: „Hány lakótárs hagyja figyelmen kívül a közleményeket? Push értesítéssel ez véget ér."

## 8. Funnel stage
- **Consideration** — megkülönböztető feature a versenytársakkal szemben (nincs natív app)
- **Retention** — telepített PWA ikon növeli a napi aktív felhasználók számát
