# v0.8.0 — Tier 1 stack-audit follow-up (Observability + Job Queue + Test framework)

## Feature name and version
- **Technical name:** Tier 1 AI-Stack Audit follow-up — Observability, pgmq job queue, pg_partman, Vitest framework
- **Version:** v0.8.0
- **Date:** 2026-05-21

## One-sentence user-language description
panellako moves from "best-effort logs" to a real production-grade backend with error tracking, structured logs, durable job queues with idempotency, log retention that does not balloon, and automated tests — all on free tiers.

## Problem it replaces
- Silent server-side failures (the only signal today is rows in `platform_job_logs` and Vercel's default unstructured logs).
- No durable job retry / dead-letter route — a failed transit sync or NDVI render either retries forever on the next cron tick or disappears.
- An unbounded `platform_job_logs` table that would dominate the database footprint within 60–90 days.
- Zero automated test gate — every release was verified manually via the `end_to_end_full_stack_verification.prompt`.
- No browser-side crash reporting for the leaflet/map regressions documented in `codingLessonsLearnt.md`.

## Primary beneficiary persona(s)
- **Solo / 2-engineer team** — gains real production observability without paying enterprise-tier prices.
- **Building-manager end users (indirect)** — fewer silent failures means fewer "the page is blank" / "the data is stale" incidents.
- **Future enterprise prospects** — having Sentry + structured logs + retry queues + a test framework is table-stakes for SOC2-curious customers.

## Marketing-ready claim
"Production-grade backend reliability — built on free tiers. Every error tracked, every background job durable and idempotent, every release covered by automated tests."

## Claim types enabled
- **Reliability / error reduction** — Sentry replay + structured logs + DLQ
- **Cost reduction** — entire Tier 1 stack runs on free tiers (~7 €/hó total)
- **Compliance readiness** — structured audit-grade logs, error tracking, retention policy
- **Visibility** — real-time error dashboard, queue depth metric, latency timing
- **Operational maturity** — idempotency keys prevent duplicate work, DLQ catches what fails

## One-sentence user-language description (Section B)

## Problem it replaces (Section B)

Egy `SUPABASE_SERVICE_ROLE_KEY` véletlen client-bundle-be kerülése észrevétlenül átment volna — ahogy a v0.7.18 build-hiba is csak production-build-kor derült ki.
