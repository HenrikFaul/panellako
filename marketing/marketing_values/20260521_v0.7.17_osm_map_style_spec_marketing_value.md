# v0.7.17 — OSM custom map style spec

**Feature name:** Beautiful OSM Custom Map Style Spec
**Version:** v0.7.17
**Date:** 2026-05-20

## One-sentence user-language description

Panellako maps now follow a single design constitution that guarantees every street, tram line, pharmacy, school and cycle route stays legible — even when the map is in night-mode, in nature-mode, or in our most stylized brand-mode.

## Problem it replaces

Until now each map surface (dashboard mini-map, environment page, Budapest transit analyzer, cycling explorer, building viewer) drifted on its own. Some pages hid residential roads "for cleanliness"; others used tram colors that disappeared on dark backgrounds; others scaled house numbers down to unreadable sizes at apartment-finding zoom. The result: a user comparing flats had to *re-learn the map* on every page, and accessibility was unverifiable.

The new spec freezes a data-first, beauty-second contract: navigation-critical and information-critical OSM features may **never** be hidden for aesthetic reasons, four canonical themes are codified, WCAG AA is enforced, and a CI gate blocks any future PR that tries to delete a load-bearing layer.

## Primary beneficiary personas

1. **Flat hunters / urban residents** — the end users; they now get the same legibility everywhere in the app, day or night, across the four themes.
2. **Color-blind users** — the spec mandates deuteranopia/protanopia and tritanopia palette variants for the cycling network and the tram/metro color codes.
3. **Designers and map engineers (internal)** — they now have a deterministic styling target instead of bespoke per-page styling.
4. **Marketing** — they can finally produce a maximalist DLC-Brand map for hero screenshots that *still* answers real navigation questions.

## Marketing-ready claim

> "Panellako maps are built data-first: every tram stop, pharmacy, school and cycle route stays visible in every theme — including our high-contrast night mode and our cyberpunk brand mode. Beautiful maps that never hide what you need to find."

## Claim types enabled

- **Accessibility leadership** (WCAG AA across all themes, color-blind sub-palettes)
- **Trust / reliability** (no map surface is "lying" by hiding data)
- **Visual differentiation** (DLC-Brand theme is genuinely brand-recognizable, not stock OSM)
- **Decision-support fidelity** (a real-estate-decision UI surface designed by an explicit doctrine, not by mood)
- **Engineering rigor** (renderer-agnostic spec, CI guard, performance budgets, four themes all under measurable draw-ms caps)
