# Controller

Ez a repo a PanelLakó MVP webalkalmazás forrása.

## Kötelező működés
- Next.js + TypeScript + Tailwind stack használata.
- Supabase kapcsolat env alapú konfigurációval.
- Minden változás kerüljön be a `CHANGELOG.md` fájlba.
- Új technikai tanulság kerüljön be a `codingLessonsLearnt.md` fájlba.
